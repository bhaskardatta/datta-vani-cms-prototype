# 0009. People translate; the CMS never machine-translates

**Status:** Accepted · **Source:** team meeting, 15 Nov 2026

## Context
The content is religious and moral teaching for children. A wrong word matters, and a machine translation that looks finished is likely to be published without a careful read.

## Decision
The editor shows the English source next to the Telugu or Kannada box. It never fills in, suggests or pre-translates text. An empty translation is shown as missing and blocks that language from going live.

## Consequences
- Translator time, not tooling, sets the pace of Priority 1 (see the handover risks).
- Coverage per language in the Library is the main progress signal for the team.
- Revisit only as an explicit team decision, not as an editor convenience.
